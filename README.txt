# 유어메리데이 홈페이지

- `index.html`: 홈페이지 메인 파일
- `robots.txt`: 검색엔진 크롤링 안내 (게시 후 실제 주소로 수정 필요)
- `sitemap.xml`: 사이트맵 (게시 후 실제 주소로 수정 필요)

## 무료 게시 방법 (GitHub Pages)
1. GitHub에 로그인하고 새 **Public repository**를 만드세요.
2. 이 폴더의 파일을 저장소 최상위에 업로드하세요.
3. 저장소의 **Settings → Pages**로 이동하세요.
4. **Deploy from a branch**를 선택하고 `main` / `/(root)`를 선택한 뒤 저장하세요.
5. 공개된 `https://계정명.github.io/저장소명/` 주소가 생성되면 `robots.txt`와 `sitemap.xml` 안의 예시 주소를 실제 주소로 바꿔 업로드하세요.
6. 네이버 서치어드바이저에서 사이트를 등록하고 소유 확인을 진행한 뒤 사이트맵을 제출하세요.

주의: GitHub Pages는 HTML 파일을 무료로 게시하지만 계정 로그인, 저장소 생성, 파일 업로드와 게시 설정은 사용자가 직접 완료해야 합니다. 무료 GitHub Pages는 공개 저장소가 필요할 수 있으므로 업로드 전 공개 범위를 확인하세요.
