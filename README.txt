유어메리데이 홈페이지 v2
- index.html: 기존 Google Sites의 카드형 레이아웃과 색감에 맞춘 홈페이지
- robots.txt: 검색엔진 크롤링 안내
- sitemap.xml: GitHub Pages 공개 주소 기준 사이트맵

업데이트 방법:
1. GitHub 저장소 https://github.com/thdgml1893/yourmarryday 에 들어갑니다.
2. Add file → Upload files를 누릅니다.
3. 압축을 푼 파일 4개를 업로드합니다.
4. 기존 파일과 같은 이름이면 새 버전으로 교체되도록 업로드한 뒤 Commit changes를 누릅니다.
5. GitHub Pages 배포 완료 후 https://thdgml1893.github.io/yourmarryday/ 에서 확인합니다.
